# OMNIBUS-GF180

A single-die, physically recurrent experimental agent designed to implement and test multiple consciousness-theory-derived mechanisms **simultaneously**.

Start with [STATUS.md](STATUS.md) for what is implemented and what remains.
[DESIGN_PLAN.md](DESIGN_PLAN.md) is the intended normative design.

[REQUIREMENTS_LEDGER.md](REQUIREMENTS_LEDGER.md) distinguishes source criteria, implementation obligations and current evidence. [CLT_REFERENCE.md](CLT_REFERENCE.md) preserves the author's Critical Loop Theory postulates and identifies definitions needed to test them.

Status: executable architecture with a first [transistor-level state primitive](circuits/README.md), 2026-10-25. No complete circuit implementation, measured layout area, or fabricated implementation yet. This is a new project, not a modification of the KianV/LNP64 CPU.

An [executable reference model](model/README.md) now connects recurrent spatial grouping and sparse quality coding to evidence-dependent workspace queries and inspection, with two persistent sensory-reliability learners. Run `python3 -m unittest discover -s tests -v`. This partial agent is not evidence of full-agent or silicon completion.

Architecture: a purpose-built predictive perceptual agent, not a generic neural fabric. Explicit prediction/error circuits, a two-candidate coherent workspace, a higher-order observer, and a separate attention model/controller must cooperate on the same task family in one frozen configuration. Their named variables and equations determine circuit counts; 192 primary states and 3,072 weighted paths are planning ceilings, not quotas. Functional placement replaces the mandatory six-tile ring.

Retain 96 simultaneous analog capture channels, 32 intervention sites chosen for functional dissociations, and a host-independent fixture. Eight bounded analog regional gain servos share the 40-state auxiliary pool; the observer includes estimate-reliability states and action selection includes explicit outcome preferences. A passive external-instrument injection loop brings assigned signals to 38. The 10.5 mm² internal envelope allocates 9.3 mm² to blocks and 1.2 mm² to global physical overhead/margin; fit remains unverified. Reuse Svalbard's analog-pad work with application-specific qualification. IIT/field measurements remain limited experiments, not compliance claims. Snapshot validity is separate from readout rate; replay does not create simultaneous whole-fabric observations.

Success means verified mechanisms in one autonomous configuration, not proof of consciousness or universal theory compliance.

[PRIMITIVE_AUDIT.md](PRIMITIVE_AUDIT.md) lists the reference model's nonlinear arithmetic, comparator and storage obligations. The model is not yet a circuit-qualified GF180 implementation; state counts must not be used as area estimates.

[Joint composition evaluation](JOINT_EVALUATION.md) records 72/72 successful grouping-and-answer cases under fixed model parameters, with explicit coverage limitations. Run `python3 -m model.evaluate` to reproduce.

[Causal-model screening](CAUSAL_MODEL_STATUS.md) documents agent-derived transition tables, boundary sensitivity and pinned IIT 4.0 (2023) system-φₛ calculations. The tested coarse candidates return zero in all defined states; this neither establishes an integrated candidate nor determines the whole agent's integration. Structure Φ has not been computed.

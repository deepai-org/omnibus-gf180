# OMNIBUS-GF180

A single-die, physically recurrent experimental agent designed to implement and test multiple consciousness-theory-derived mechanisms **simultaneously**.

Start with [DESIGN_PLAN.md](DESIGN_PLAN.md).

Status: architecture proposal, 2026-10-25. No schematics, RTL, trained network, measured area, or fabricated implementation yet. This is a new project, not a modification of the KianV/LNP64 CPU.

Architecture: a purpose-built predictive perceptual agent, not a generic neural fabric. Explicit prediction/error circuits, a two-candidate coherent workspace, a higher-order observer, and a separate attention model/controller must cooperate on the same task family in one frozen configuration. Their named variables and equations determine circuit counts; 192 primary states and 3,072 weighted paths are planning ceilings, not quotas. Functional placement replaces the mandatory six-tile ring.

Retain 96 simultaneous analog capture channels, 32 intervention sites chosen for functional dissociations, and a host-independent fixture. The provisional 10.5 mm² internal envelope allocates 9.1 mm² to blocks and 1.4 mm² to global physical overhead/margin; fit remains unverified. Reuse Svalbard's analog-pad work with application-specific qualification. IIT/field measurements remain limited experiments, not compliance claims. Snapshot validity is separate from readout rate; replay does not create simultaneous whole-fabric observations.

Success means verified mechanisms in one autonomous configuration, not proof of consciousness or universal theory compliance.

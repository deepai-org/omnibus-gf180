# OMNIBUS-GF180

A single-die, physically recurrent experimental agent designed to implement and test multiple consciousness-theory-derived mechanisms **simultaneously**.

Start with [DESIGN_PLAN.md](DESIGN_PLAN.md).

Status: architecture proposal, 2026-10-25. No schematics, RTL, trained network, measured area, or fabricated implementation yet. This is a new project, not a modification of the KianV/LNP64 CPU.

Revised baseline: 192 primary nodes, 3,072 dedicated edges, six tiles, and a provisional 10.5 mm² internal envelope. Prioritize simultaneous analog capture (192 channels targeted, 96 fallback), 32 clampable nodes, registered same-die controls and explicit action-copy/attention tests over node expansion. Include limited adaptation, gain calibration and passive coupling coupons, but no active field-feedback driver. The expanded 9.1 mm² block allocation leaves only 1.4 mm² for global physical overhead and margin: fit remains unverified. Reuse Svalbard's analog-pad work, with application-specific qualification.

Success means verified mechanisms in one autonomous configuration, not proof of consciousness or universal theory compliance.

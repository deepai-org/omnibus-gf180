# Endogenous field-loop scope decision

## Requirement, not a label

The selected authority is McFadden's [2020 CEMI paper](https://pubmed.ncbi.nlm.nih.gov/32995043/): its proposed conscious substrate is causally active information in the brain's global electromagnetic field. Passive monitoring and external injection do not implement an endogenous computational field loop. Ordinary circuit operation involving electromagnetic fields is not, by itself, evidence for this distinctive proposal.

**Decision:** the intended baseline still does not satisfy CEMI. Do not count it among simultaneously implemented theories. Keep passive characterization and external injection as limited experiments. No endogenous loop is qualified for inclusion yet; the engineering candidate below is a feasibility investigation, not another promised functional block or an assertion of fit.

## Smallest candidate worth investigating

A shared electrostatic coupling region is a more relevant candidate for this slow agent than an RF carrier fabric:

1. Several distinct agent populations drive separate emitting electrodes through bounded buffers. Emitters carry actual agent activity, not a test generator during the primary condition.
2. Several electrically isolated receiving electrodes couple to the shared spatial field. Each receiver's effective transfer depends on multiple emitters and extracted geometry, rather than an assumed scalar global-gain wire.
3. Receiver currents modulate already allocated inference/attention states, closing a field-dependent path back into the agent. No additional task solver or hidden digital controller is introduced.
4. Matched-load switches disable or replace the field path for causal controls while preserving relevant emitter/receiver loading.

This is an engineering hypothesis about a possible circuit organization. It is not a demonstrated CEMI implementation. In particular, a capacitance matrix or a scalar weighted sum cannot be declared sufficient for the theory without justifying what information is spatially integrated and how it contributes to behavior.

## Go/no-go evidence before changing the baseline

- Extract the complete multi-electrode capacitance/conductance network, including substrate, shields, pads, ESD and power-grid effects. Do not replace it with arbitrarily chosen coupling coefficients in the agent model.
- Demonstrate a useful endogenous transfer over the actual agent bandwidth with stable bias, signal-to-noise ratio and legal terminal voltages. Purely capacitive coupling does not preserve DC information; quantify what changes or temporal structure it can transmit and what receiver memory is needed.
- Show activity-to-field-to-state-to-action influence during the same task that exercises other mechanisms. Recorded pickup correlated with action is insufficient.
- Compare connected, field-path disabled, matched conducted replacement, matched loading, and supply/substrate-injection conditions. A behavior change caused by supply droop or heating is not the claimed demonstration.
- Include driver, bias, receiver, protection, switches, routing and field-region area in the existing die ceiling. No reliable area number is assigned until a concrete layout exists.
- Declare exactly which CEMI-derived condition this tests and which theoretical identity/integration claims it cannot establish. Obtain a theory-specific assessment rather than treating the presence of a capacitor as automatic compliance.

If these gates pass, explicitly revise the active-field-driver exclusion and replace existing paths/area allocations rather than silently exceeding the budget. If they fail, CEMI remains unmet; negative coupling results still have their limited physical meaning. This decision does not prevent completing the recurrent perception/workspace/observer/schema agent.

## Prior consolidation baseline

The preceding 98-state reference agent integrated scene organization, sparse quality
populations, query-driven retrieval/inspection/comparison, partial monitoring,
attention control and bounded outcome learning. Unit/intervention tests and
development task grids are evidence of software behavior, not silicon fit or
consciousness. See JOINT_EVALUATION.md for task boundaries and adverse cases.

The inspection deadlock is fixed: completion can follow either estimated
actuator position >0.95 **or** usable evidence (retained stability >0.9,
grouping confidence >=0.85, observer admission). Comparison and report validity
still enforce those evidence conditions. An unreachable actuator position no
longer blocks a correct report merely because its numeric target was not met.
Insufficient/ambiguous evidence does not qualify, even at actuator completion.

`python3 -m experiments.attention_task` exercises model-based, direct-feedback
and command-only control with identical estimator state retained. All 18
gain/time-constant combinations now report correctly. Previously all six
gain-0.65 cases timed out despite correct grouping. Direct feedback remains
slightly faster in all six matched plant conditions; this experiment does not
establish a distinctive attention-schema benefit. It is a control-path
intervention, not a whole-schema lesion.

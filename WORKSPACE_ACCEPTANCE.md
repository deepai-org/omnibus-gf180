# Workspace objective: closeout assessment

This assesses the requested content-bearing workspace transformation, not
consciousness or manufacturability. Work is intentionally stopped short of a
claim of full completion. The compact experimental configuration is
`experiments.decoded_agent.configured`; the model-owned joint reference remains
`model.configuration.joint_configured`. Do not merge results across them.

| Requested requirement | Current evidence and limit |
|---|---|
| Two content populations with reinforcement, inhibition, feedback and release | Implemented in `model/content_workspace.py`, integrated in `model/agent.py`. Compact candidate task and reversal checks are in `tests/test_decoded_timestep.py`; persistence/feedback audit is in `experiments/decoded_agent_audit.py`. This is behavioral evidence, not proof of a GNWT consciousness criterion. |
| Query controller depends on maintained content | Agent supplies maintained grouping/quality to retrieval and query processing. The query controller is not relabeled as the content workspace. |
| Useful reciprocal sensory, memory, observer and acquisition interactions | Contextual distractor and selective-broadcast experiments show useful cross-specialist dependencies. Direct observer and memory persistence cuts are not individually necessary in this task; the stronger requested necessity claim remains incomplete. |
| Differentiated interacting states | The compact agent retains sensory, content, observer, context, query and attention state separately. State inventory and transition reconstruction are checked in `tests/test_decoded_causal_contract.py`. Separate state variables alone do not establish intrinsic irreducibility. |
| Complete small causal motif with explicit boundary and inputs | Complete acquisition bookkeeping exists (94 coordinates, 90 dynamic plus four fixed learned coordinates). A smaller exact model exists only for the withdrawn-input phase. Neither is the requested small complete acquisition motif. The eight-unit label proposal fails closure and is rejected. |
| Compare partitions and alternative candidate subsets | Three declared acquisition boundaries have nominally matched two-way replay cuts. `tests/test_decoded_partition.py` checks transmission blocking and preservation under reduction. These are causal controls, not IIT's partition measure or an exclusion search. |
| Ignition, persistence, release | Strength/duration and withdrawal experiments exist, with live versus cut/replayed returns. Numerical robustness now includes two timestep sizes for compact-candidate task and switching behavior. This does not certify every dynamical statistic against timestep changes. |
| Broadcast disruption preserving local perception | Ambiguous cross-specialist task fails under outgoing-prior removal while fully exposed clear cases retain perception and answers in the selective-broadcast audit. |
| Justified IIT analysis, separately from causal dependence | Not achieved for the current workspace. Historical solver results describe older models. No positive IIT quantity is claimed for this candidate. |

## Decision boundary

The current stopping point is a credible programmable-agent configuration and
an explicit account of its limitations. It is not a completed proof that one
chip satisfies every theory. A future attempt to close the causal-model gap
requires an architectural decision about a smaller complete motif, not another
favorable subset selected from hidden surrounding dynamics. Hardware realization
also remains separate work. No further mechanisms are added at this checkpoint.

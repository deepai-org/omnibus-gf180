# Single-die theory requirements ledger

This ledger tracks the attached objective's source-backed criteria and current authoritative evidence. It is not a consciousness score. The repository contains a closed perception/query/inspection assembly and reliability-learning components, not yet the complete agent, transistor implementation or physical verification. A required function in DESIGN_PLAN.md is not an implemented function.

Statuses: **unverified** = specified but not demonstrated; **missing** = required implementation or definition absent; **incompatible** = excluded by the current intended design. These statuses are independent of scientific acceptance of the source theory. All criteria must coexist on one die in the same primary configuration; separate test networks do not substitute.

Authority **B23** means Butlin et al., [2023 v3](https://arxiv.org/html/2308.08708v3), Sections 2.1–2.5 and Table 2. These are theory-derived indicators, not universal necessary-and-sufficient tests. The groupings and implementation tests below are engineering interpretations.

## Completion evidence for the attached objective

Revision qualification: the source-hashed binary results in evidence/iit are
historical after the inspection-deadlock fix. The current continuous causal
model and intervention tests do not imply a positive IIT result. The
current agent can request missing evidence before convergence and retains
72/72 clean composition results. Accumulated representation stability now
restores correct reports in all 24 synthetic correlated-noise development trials
(σ=0 through 0.05). Intrinsic noise, mismatch, calibration and nonstationary
evidence remain unqualified; this is not a satisfied HOT noise criterion or a
completed joint-agent demonstration.

1. **Perceptual organization:** runnable spatial scene generator, grouping dynamics, binding representation and selective-deficit tests.
2. **Sequential workspace:** query-state equations and traces of evidence-dependent specialist recruitment without scripted agent stages.
3. **Representation geometry:** explicit sparse population code, distance/generalization tests and demonstrated downstream use.
4. **Learning decision:** bounded update equations and state/circuit cost; adopted norm or an explicit unmet criterion, not a gain-servo relabeling.
5. **IIT/CEMI/CLT:** agent-derived small causal models and analysis; explicit endogenous-field feasibility/scope decision; formal CLT definitions and tests based on the supplied postulates.
6. **Joint executable agent:** one parameterized model using intended circuit primitives, same-configuration joint tests, intervention controls, state/path inventory and reproducible results. Software success is not silicon qualification.

Evidence: `python3 -m unittest discover -s tests -v` exercises grouping, ambiguity, feedback-gain ablation, population geometry, timestep refinement, recurrent context restoration/basin limits, removed-cue retrieval across three delays, memory interventions, state accounting, hidden-input isolation, reliability learning, outcome-driven choice/reversal, frozen evaluation, query logic/lesions, attention control, observation, checkpoints and causal boundary sensitivity. `python3 -m model.evaluate` additionally passes 72/72 joint composition cases under fixed parameters; see JOINT_EVALUATION.md for why this is not the plan's complete temporal battery. Integrated tests connect perception, workspace, inspection and observation; they test stale-answer invalidation and separate reporting from first-order grouping under an observer clamp. Adverse attention-control cases remain recorded. This does not demonstrate all requested mechanisms together, broad agency, transistor feasibility or any complete consciousness theory. See model/README.md, PRIMITIVE_AUDIT.md, CAUSAL_MODEL_STATUS.md and FIELD_LOOP_FEASIBILITY.md for implementation, physical-lowering, transition-model and CEMI limitations. CLT mathematical closure, full higher-order observation, stronger attention-model validation and IIT computation/substrate comparison remain open; no endogenous-field implementation is qualified.

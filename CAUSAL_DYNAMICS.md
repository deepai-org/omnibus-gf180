# Implemented recurrent dynamics and causal boundary

This is the primary causal model of the **implemented attention loop**, not an
IIT discretization or a claim about the entire intended chip. The independently
written executable equations are in `experiments/attention_dynamics.py`.
They retain the actual seven continuous state coordinates of one stream.

## State and input

`x = (a0,a1,a2,a3,f,e,p)`, each in [0,1]: four physical aperture states,
measured telemetry, estimated allocation, and predicted telemetry. The input
`u` is desired inspection. In the complete agent, u is another dynamic state
driven by workspace inspection activity; it is **not exogenous there**.

The analysis boundary explicitly conditions on a supplied u(t) trajectory.
Given x, u and immutable parameters, no omitted agent state enters the next
attention state. This is input-conditioned causal closure. It is not autonomous
closure, a closed thermodynamic system, or a qualified intrinsic IIT substrate.

## Equations

Let `sat(z) = min(1,max(0,z))`, actuator gain g, and
`tau_i = tau * (0.8,1,1.2,1.4)_i`. Default g=tau=1.

```text
c       = sat(5u - 4e)
da_i/dt = (g*c - a_i)/tau_i
df/dt   = (mean(a) - f)/0.5
de/dt   = (c - e)/1.1 + 8*(f - p)
dp/dt   = (e - p)/0.5
```

The current software realization is bounded forward Euler:
`x_next = sat(x + dt*drive(x,u))`, with `0 < dt <= 0.025`.
Telemetry is a convex update and needs no active clipping in this domain;
the independent implementation's clip on it is redundant. The equations above
are the interior drift. At a boundary, saturation limits outward motion.
A finite-step clipped integrator is not a proof of a transistor implementation
or of exact continuous-time trajectories.

This contains real feedback paths: e→c→a→f→e and e→p→e. They can become
locally ineffective when saturated; merely drawing cycles does not establish
irreducibility or positive integrated information.

## Intervention semantics

- A state intervention sets any subset of these seven physical-model variables
  to declared values in [0,1], then releases them to the equations. There is no
  hidden renormalization or binary thresholding of the response.
- A command intervention replaces u(t) at this boundary. It must not be called
  an intervention solely on the internal seven-state subsystem.
- A matched-input comparison holds the entire u(t) trajectory fixed, not just
  its initial value. If u is allowed to respond to a changed agent state, the
  rest of the agent must be simulated too; replay is then a different causal
  experiment, not a substitute.
- No probability distribution over these interventions is implicit. The test
  grid is a deterministic numerical audit, not an IIT maximum-entropy noising
  prescription or a measured biological distribution.

## Verified correspondence

Run:

```sh
python3 -m unittest discover -s tests -p test_attention_dynamics.py -v
python3 -m unittest discover -s tests -p test_attention_boundary.py -v
```

The independent equations match the actual component for all 128 endpoint
state interventions, three desired commands, and three gain/time-step/time-
constant settings (1,152 one-step comparisons). They also match a 500-step
interior-state/random-command trajectory and an 800-step command trajectory
generated by the complete agent, to declared floating-point tolerances.
The unused stream is varied independently. The tests additionally verify
the named recurrent influences around an unsaturated operating point.

These comparisons test implementation correspondence; they do not prove all
possible real-valued trajectories. The algebra supplies the boundary argument:
the seven update equations depend only on x, u, g and tau. All coefficients,
input handling and saturation in the actual `Attention.step` must remain in
agreement; the tests are intended to catch future divergence.

## Why the earlier reductions were inadequate

The earlier four-coordinate attention surrogate omitted three aperture states
that directly drive f. Replacing four apertures with one mean also loses state:
their distinct time constants make the next mean depend on their distribution.
Both failures have executable counterexamples in `test_attention_boundary.py`.
Neither omission exists in this seven-coordinate model.

This resolves the **continuous-state controlled-component model**, not binary
bin closure. Arbitrary 0/1 thresholding, or holding omitted state at a convenient
checkpoint, cannot silently turn it into an autonomous IIT TPM.

## Whole-agent boundary and remaining gaps

To analyze the complete perception–inspection–workspace loop, use the 98-state
agent with explicit external scene, visibility, cue, reward and validity inputs.
`Agent.state_vector/set_state` retain its dynamic state. Parameters, intervention
flags, forced source, future input trajectory and timestep are separate context.
The seven-state component does not replace those causes or claim to identify
the whole agent's experiential boundary.

A future intrinsic-substrate analysis must explicitly justify conditioning or
noising u and other external causes, admissible state/temporal grains, and
exclusion alternatives. No positive IIT result follows from this document.
CLT's quantitative functional remains undefined; CEMI's endogenous field loop
is absent; HOT/AST benefits and complete GWT/active-inference coverage remain
limited as recorded in REQUIREMENTS_LEDGER.md.
